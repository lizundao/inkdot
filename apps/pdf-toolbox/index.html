产品简介

PDF 工具箱是一款面向 Windows 与 macOS 的离线 PDF 多功能桌面软件，集成压缩、页面编辑、格式转换、水印、安全隐私、脱敏涂黑、扫描增强、预览等功能于一体。所有处理均在您的电脑本地完成，无需联网、不上传文件。

核心特点

完全离线文件在本地处理，不上传云端（Office 转 PDF 会调用本机 Office）
自由使用依据 MIT 许可开放，无会员、无广告、无内购
绿色便携便携版解压即用，不写注册表，删文件夹即卸载
中文友好界面中文，水印支持系统字体（微软雅黑、宋体等）
拖放操作各工具页支持将 PDF / 图片 / Office 文件拖入窗口
智能输出自动建议输出路径：原文件名-功能名.pdf，与源文件同目录

功能一览

压缩结构流压缩，批量处理
扫描增强内嵌图片 JPEG 重压缩、降分辨率、转灰度
页面工具合并、拆分、提取、删除、旋转、重排、插入、裁剪、统一尺寸、去空白页
格式转换图片↔PDF、PDF↔文本、Office→PDF、PDF 批量导出图片
水印版式文字 / 图片水印、页眉页脚、页码
安全隐私加密、解密、清除元数据
脱敏涂黑预览框选敏感区域，输出涂黑 PDF
预览信息内置预览、缩略图、元数据查看与编辑

系统要求

操作系统Windows 10 / 11（64 位）；macOS Apple 芯片（aarch64）
内存建议 4 GB 及以上
磁盘空间约 50 MB
Office 转 PDF需本机已安装 Microsoft Word / Excel / PowerPoint
运行时Windows 需 WebView2 运行时（Win10/11 通常已预装）
关于脱敏：涂黑层覆盖在内容上方，一般阅读看不到，但底层文字理论上仍可能被专业工具提取。高敏感场景建议配合「清除元数据」，或打印后再扫描。

使用说明

安装与运行：下载便携版 zip 并解压到任意目录，双击 pdf-compress.exe 启动；macOS 打开 dmg 将应用拖入「应用程序」。便携版删文件夹即卸载，不写注册表。

通用流程：左侧进入功能 → 选择或拖入文件 → 确认输出路径（通常已自动填好）→ 设置参数 → 点击「开始处理」。输出文件默认与源文件同目录，命名为 原名-功能.pdf，例如 报告.pdf → 报告-压缩.pdf。

中文水印：在「水印版式 → 字体」选择微软雅黑、宋体等系统中文字体，避免显示方块。

常见问题

检查是否被杀毒软件拦截；尝试右键 → 以管理员身份运行；确认是 64 位 Windows。
软件尚未购买代码签名，属正常现象。点击「更多信息」→「仍要运行」即可。
默认与源文件同目录，文件名带功能后缀（如 报告-压缩.pdf），不会覆盖源文件，除非手动把输出路径设为与源文件相同。
在「水印版式 → 字体」选择微软雅黑、宋体等中文字体，不要留空。
涂黑层覆盖在内容上方，一般阅读看不到，但底层文字理论上仍可能被专业工具提取。高敏感场景建议配合「清除元数据」，或打印后再扫描。
